# Lazurite 運営ボード

民泊6施設の売上ダッシュボードと、予約ごとのメモ・Todoを1つにまとめたWebアプリです。

- 公開先:GitHub Pages
- データ:Supabase(予約・売上・メモ・Todo)。ログインした人だけが読み書きできます。
- ログイン:招待済みのメールアドレスに届くリンク、または6桁コード

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/style.css` | 見た目 |
| `js/config.js` | Supabaseの接続先(公開しても安全なキーのみ) |
| `js/app.js` | ログイン・集計・メモ/Todoの処理 |

このリポジトリには予約データや顧客情報は含まれていません。
